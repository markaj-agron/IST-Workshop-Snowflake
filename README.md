# Advantages and disadvantages of Snowflake

## Advantages

- cloud storage: 
- real time scalability: huge quantities of rows of data can be processed at the same time.
- wide feature set
- Good security and data protection : data is encrypted at rest and in transit, access levels can be controlled, IP allows and blocklists.
- Time Travel and Fail-Safe
- Data caching
- Micro partitions
- Fast data ingestion

## Disadvantages

- Cost
- No on-premise deployment
- Unpredictable pricing: on-demand pricing, charged per seconds (minimum 60 seconds)
- Small comunity of users
